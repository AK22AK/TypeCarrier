# 0.1.4 Beta

[English](0.1.4.en.md)

本轮仅发行 iOS TestFlight 小版本；Mac / Android 源码版本同步，不代表已发布新的 GitHub 安装包。

## 更新内容

- 优化多设备连接：iPhone 每次只向当前 Mac 发送，默认选择最先连接成功的设备，目标断开后自动切换到仍在线的设备。
- 改善接收与超时处理：Mac 按接收顺序处理多部手机的文本；5 秒未收到接收确认时，手机保留输入，不自动重发。
- 草稿与发送历史独立保存：草稿不再被历史清理，历史可按条数或时间保留。
- 支持自定义设备名称，简化名称查看、编辑与保存；长设备名保持正常字号并省略显示，滚动页面顶部过渡更柔和。
- 改善 Mac 菜单栏与窗口入口：打开管理窗口时显示 Dock，关闭窗口后继续后台接收。

## TestFlight 测试说明

请使用兼容本轮改动的 Mac 客户端测试：

1. 单设备发送、接收确认，以及超时后输入保留。
2. 草稿和历史保留设置；名称编辑、取消、选择系统名称后保存。
3. 有多台 Mac 时，目标选择、断线自动切换，以及每条消息只到达当前目标；多部手机向同一 Mac 发送时的接收顺序。
4. 历史、设置与详情页的顶部滚动过渡。

单设备已有使用反馈；本轮尚未完成多 Mac／多手机真机组合验证，请反馈这些场景中的异常。手机成功确认表示 Mac 已保存接收记录，目标应用的粘贴结果请在 Mac 侧检查。

## 发行范围

- iOS 26.0 或更新版本，通过 TestFlight 测试，不提交 App Store 生产审核。
- 配套 Mac 客户端需要包含本轮源码改动；本次不公开新的 Mac DMG 或 Android APK。
- 不包含云同步、互联网中转或 Windows 支持。
