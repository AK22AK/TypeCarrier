# 0.1.5 Beta

[English](0.1.5.en.md)

本轮发行 iOS TestFlight 更新；Mac / Android 源码版本同步，不代表已发布新的 GitHub 安装包。

## 更新内容

- iPhone 导航更稳定：从历史、设置等页面返回首页时标题栏不再跳动；历史页打开时直接显示展开的大标题和记录数。
- iPhone 多台 Mac 在线时，发送目标入口改为无底色文字加右箭头，与连接副标题对齐。
- Mac 管理窗口按系统设置风格重新整理：常驻侧栏、接收列表三列适配 740 点窗口宽度，详情占满可用宽度。
- Mac 接收记录先阅读、需要时再编辑：阅读时可选中文本并略增行距；点“编辑”后使用大输入框，需显式保存或取消。
- Mac 编辑数据保护：有未保存修改时，切换记录、关闭窗口或退出前都会确认；保存失败时保留已输入的文字。

## TestFlight 测试说明

请使用包含本轮源码改动的 Mac 客户端测试：

1. iPhone 首页与历史、设置之间来回切换和侧滑返回，标题栏是否稳定；历史页打开时大标题是否展开。
2. 连接多台 Mac 时，目标入口的显示与切换。
3. Mac 接收记录的阅读、编辑、保存、取消，以及有未保存修改时切换记录、关闭窗口和退出。
4. Mac 管理窗口在默认尺寸和拉大后的布局。

多 Mac／多手机真机组合仍未完成完整验证，请反馈这些场景中的异常。手机成功确认表示 Mac 已保存接收记录，目标应用的粘贴结果请在 Mac 侧检查。

## 发行范围

- iOS 26.0 或更新版本，通过 TestFlight 测试，不提交 App Store 生产审核。
- 配套 Mac 客户端需要包含本轮源码改动；本次不公开新的 Mac DMG 或 Android APK。
- 不包含云同步、互联网中转或 Windows 支持。
