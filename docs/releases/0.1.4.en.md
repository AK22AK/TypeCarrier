# 0.1.4 Beta

[中文](0.1.4.md)

This release distributes an iOS TestFlight update only. Mac and Android source versions are aligned; this does not announce new GitHub install packages.

## Changes

- Improved multi-device connections: iPhone sends to one selected Mac, chooses the first connected Mac by default, and switches to an online Mac if the target disconnects.
- Improved receipt handling: Mac processes text from multiple phones in arrival order. If no receipt arrives within five seconds, iPhone keeps the input without retrying automatically.
- Separated drafts from sent history, with configurable history retention by count or time.
- Added custom device names and clearer editing controls, readable long-name truncation, and softer transitions at the top of scrolling pages.
- Improved Mac menu bar and window access, with a Dock icon while the management window is open and background receiving after it closes.

## TestFlight testing notes

Use a Mac client compatible with this update. Please test:

1. Single-device sending, receipt confirmation, and input retention after a timeout.
2. Draft and history retention settings, plus name editing, cancellation, and saving a system-name selection.
3. With multiple Macs: target selection, automatic switching after disconnection, and delivery to only one target. With multiple phones: receive order on one Mac.
4. Top-edge scrolling transitions in history, settings, and text details.

Single-device use has received feedback; multi-Mac and multi-phone combinations have not yet completed real-device validation. Please report issues in those scenarios. A successful phone receipt means the Mac saved the text; check the paste result on the Mac.

## Distribution scope

- iOS 26.0 or later, via TestFlight; no App Store production review submission.
- The companion Mac client must include this update's source changes. This release does not publish a new Mac DMG or Android APK.
- No cloud sync, internet relay, or Windows support.
