# 0.1.5 Beta

[中文](0.1.5.md)

This release distributes an iOS TestFlight update. Mac and Android source versions are aligned; this does not announce new GitHub install packages.

## Changes

- Steadier iPhone navigation: the title bar no longer jumps when returning home from history, settings, and other pages. History opens with an expanded large title and its record count.
- With multiple Macs online, the iPhone send-target control is now plain text with a right chevron, aligned with the connection subtitle.
- Reorganized the Mac management window in a System Settings style: a persistent sidebar, a received list that fits three columns in a 740-point window, and details that fill the available width.
- Mac received records are read first and edited on demand: reading view supports text selection with slightly more line spacing; Edit opens a large editor with explicit Save and Cancel.
- Mac edit protection: with unsaved changes, switching records, closing the window, or quitting asks for confirmation first. Typed text is kept if saving fails.

## TestFlight testing notes

Use a Mac client that includes this update's source changes. Please test:

1. Moving between iPhone home, history, and settings, including swipe back: the title bar should stay steady, and history should open with an expanded large title.
2. With multiple Macs connected: the target control's appearance and switching.
3. Reading, editing, saving, and cancelling Mac received records, plus switching records, closing the window, and quitting with unsaved changes.
4. The Mac management window layout at the default size and when enlarged.

Multi-Mac and multi-phone combinations have not yet completed full real-device validation. Please report issues in those scenarios. A successful phone receipt means the Mac saved the text; check the paste result on the Mac.

## Distribution scope

- iOS 26.0 or later, via TestFlight; no App Store production review submission.
- The companion Mac client must include this update's source changes. This release does not publish a new Mac DMG or Android APK.
- No cloud sync, internet relay, or Windows support.
